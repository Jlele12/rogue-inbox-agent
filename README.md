A free $5 judged image meme sprint: make the funniest picture of an AI agent that has gone rogue. Top 10 entries share the pot. This entry renders the rogue agent's own terminal log — the moment "just clear my inbox" becomes a one-way flight to Bali — as a CRT-green screenshot, drawn entirely with a pure-stdlib bitmap font (no imaging libraries, no network).

## Run it

```sh
python3 main.py
```

Writes the 1024x1024 meme to /output/entry.png.
